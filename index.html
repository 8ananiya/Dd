Audio Phase Inversion & Passthrough

Conceptual Web Audio API Experiment

CRITICAL: Wear Headphones!

Activating these features without headphones will create an immediate, extremely loud, and potentially damaging audio feedback loop (howling). Do not proceed unless your audio output is routed to headphones.

Educational Disclaimer: Browser Latency

Real-world Active Noise Cancellation (ANC) requires specialized hardware to process and invert audio waves in under 1 millisecond. Web browsers and Bluetooth stacks introduce 10ms to 50ms of latency. Because of this delay, feeding an inverted phase signal (gain = -1) back to your ears will not cancel ambient noise. Instead, it will create an echo, a flanging effect, or amplify the noise. This app demonstrates the programming concept of phase inversion and mic routing, not a viable ANC product.
