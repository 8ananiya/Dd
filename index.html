FxLMS Controller

Based on michalber/ANC-Headphones-repository-
  • Original: JUCE C++ with ARM CMSIS DSP, targeting Raspberry Pi + I2S mics/DAC. This is a direct port of that FxLMS implementation to the Web Audio API.
  • FxLMS (Filtered-x Least Mean Squares) with NLMS normalization — the same algorithm family used in commercial ANC chips.
  • Config defaults from the repo: μ = 0.0005, taps = 256 (original used 4192 for Pi; reduced for browser CPU).
  • DC blocker removes microphone DC offset, as the original repo requires via LADSPA plugins.
  • Browser latency (10–30 ms) limits cancellation to ~25 Hz. Commercial ANC chips run at <1 ms. This is the real algorithm, but not the real hardware.
